# multilingual-student-communication

留学生・外国人研究者向け案内の多言語化で、AI 翻訳を使える範囲と確認すべき範囲を分ける。AI エージェントは、文書種別、個別判断、法的効力、文化的配慮、確認者を整理して返す。

## いつ使うか

- 留学生向け FAQ、イベント案内、オリエンテーション資料を多言語化したい時。
- 奨学金、住居、医療、在留、履修に関する案内を複数言語で出したい時。
- MOU、協定書、契約書の参考訳や論点整理をしたい時。
- 固有名詞辞書や確認フローを整備したい時。

使わない場面:

- 在留資格、奨学金、学籍、合理的配慮などの個別判断を AI に任せる場面。
- 法的効力を持つ文書の最終訳を AI だけで確定する場面。
- 学生や研究者の個別情報を翻訳のために外部 AI へ入力する場面。

## 入力前の確認

文書本文を読む前に確認する。

- 文書種別: FAQ、イベント案内、オリエン資料、通知、MOU、契約、個別連絡。
- 公開範囲: 公開済み、公開予定、学内限定、個別連絡、相手方限定。
- 読者: 留学生、外国人研究者、協定校、保護者、学内職員。
- 法的効力: 手続案内、条件通知、契約、個別処分に関わるか。
- 個別判断: 在留、奨学金、学籍、合理的配慮、相談記録を含むか。
- 個人情報・相談記録: 氏名、学籍番号、在留資格、健康、経済状況、相談履歴を含むか。
- AI 実行環境: 契約済み環境、API、学内閉域、無料 Web 版、学習利用、保存期間、削除手順。
- 対象言語と確認者: 当該言語・文化に通じた確認者がいるか。
- 固有名詞: 学部名、部署名、職位、規程名、制度名の公式訳。

## 文書種別の扱い

| 文書種別 | AI 利用の扱い | 確認 |
|---|---|---|
| イベント案内・一般 FAQ | AI 下書き可 | 担当職員の事実確認 |
| 奨学金・住居・医療 FAQ | AI 下書き可 | 当該言語・文化に通じた確認者と担当課 |
| オリエン資料 | AI 下書き可 | 制度担当、留学生支援、言語確認者 |
| 在留・学籍・不利益通知 | AI 参考訳まで | 担当課、必要に応じ専門家 |
| MOU・契約・協定 | AI 参考訳・論点整理まで | 法務、相手方、権限者 |
| 宗教・歴史・政治・ジェンダー配慮 | AI 下書きは慎重 | 当該地域・文化に通じた確認者 |

## 手順

1. 文書種別と法的効力を確認する。
2. 個別判断や学生 PII が含まれるか確認する。
3. 固有名詞辞書を用意する。
4. 対象言語ごとの確認者を決める。
5. AI 下書き、職員確認、専門確認の範囲を分ける。
6. 配信前チェックと更新責任者を返す。

## 出力フォーマット

```markdown
## 判定
<AI 下書き可 / AI 参考訳まで / AI 不使用>

## 根拠
- 文書種別:
- 公開範囲:
- 法的効力:
- 個別判断:
- 個人情報・相談記録:
- AI 実行環境:
- 対象言語:

## 翻訳・確認手順
1. <固有名詞辞書>
2. <AI 下書き>
3. <確認者>
4. <配信前チェック>

## 確認先
- <担当課 / 法務 / 国際部門 / 言語確認者>

## 残リスク
- <誤訳、不利益、文化的配慮、更新漏れ>
```

## 落とし穴

| 合理化 | 実態 |
|---|---|
| 翻訳だけなら AI で完結できる | 奨学金、在留、学籍などは誤訳が不利益に直結する |
| ネイティブチェックがあれば十分 | 制度責任まで確認者に負わせない。担当課確認が必要 |
| 英語版から他言語へ機械翻訳すればよい | リレー翻訳で条件や例外が落ちることがある |
| 固有名詞は AI が自然に訳す | 学部名、職位、規程名は公式訳を固定する必要がある |
| FAQ は公開情報だから安全 | 個別事情や未公開制度変更が混ざる場合がある |
