# 教務・教学・入試 / Academic Affairs

教務、教学、入試に関する大学業務を AI エージェントへ頼むための skill を置きます。シラバス、授業方針、入試書類、学生への周知など、教員の判断と職員の運用が接続する領域を扱います。

## 実装済み skill

| Skill | 使う場面 | 先に確認すること |
|---|---|---|
| [syllabus-ai-policy](syllabus-ai-policy/) | シラバスに生成 AI 利用方針を記載する | 学部・教務委員会方針、科目特性、評価方法 |
| [entrance-exam-ai-policy](entrance-exam-ai-policy/) | 入試書類での AI 使用方針と疑義対応を整理する | 入試規程、出願要項、不正対応手続 |
