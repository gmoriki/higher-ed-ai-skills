# staff-ai-literacy-primer

大学職員向けの AI リテラシー研修を、大学業務の文脈で最小構成に落とす。AI エージェントは、入力前確認、プロンプトの基本、検証、所属大学ルールへの接続を含む研修案を返す。

## いつ使うか

- 新任職員研修や SD 研修に AI 基礎を入れたい時。
- 部署内で、AI を使う前の情報分類と検証を共有したい時。
- 講師経験が浅い職員が、30-60 分の研修骨子を作りたい時。
- 職員自身の AI 利用リテラシーを棚卸ししたい時。

使わない場面:

- 特定 AI サービスの詳細操作研修だけを作る時。
- 法令解釈や契約条件を確定する時。
- 実データを使った演習を行う時。研修では架空データを使う。

## 入力前の確認

研修資料や実例を読む前に確認する。

- 対象者: 新任、中堅、管理職、特定部署。
- 時間: 30 分、60 分、半日など。
- 利用可能環境: 無料 Web、法人契約、学内閉域、利用不可。
- 所属大学ルール: AI 利用ガイドライン、情報セキュリティ、個人情報保護。
- 演習で扱うデータ: 架空データか、公開情報か。
- 研修成果物: スライド、配布資料、演習、確認問題、講師台本。

## 研修の核

| 要素 | 教えること |
|---|---|
| 使い分け | 調べる、考える、まとめる、判断する、公開する、の役割を分ける |
| 入力前確認 | 本文やファイルを渡す前に、情報カテゴリと AI 環境を確認する |
| プロンプト | 役割、目的、制約、出力形式を指定する |
| 検証 | 固有名詞、数値、根拠、規程、URL を一次情報で確認する |
| 責任 | AI 出力をそのまま学生、教員、学外者へ出さない |

## 60 分構成例

| 時間 | 内容 |
|---|---|
| 0-10 分 | 大学業務で AI に頼めること / 頼めないこと |
| 10-20 分 | 入力前確認と Level 1/2/3 |
| 20-35 分 | 架空業務でプロンプト演習 |
| 35-50 分 | 出力の検証とハルシネーション確認 |
| 50-60 分 | 所属大学ルール、問い合わせ先、確認問題 |

```markdown
- <架空データを使った演習>

- <入力禁止情報、検証、所属大学ルール>

- <未確認事項>
```

## 落とし穴

| 合理化 | 実態 |
|---|---|
| 便利なプロンプト集を配れば研修になる | 入力前確認と検証がないと事故につながる |
| 無料 Web 版で実データ演習をすれば実践的 | 学生情報や内部資料を誤入力するリスクが高い。架空データを使う |
| 「判断は人間」と言えば十分 | どの段階で誰が確認するかを演習に落とす必要がある |
| AI の最新機能紹介を中心にする | 大学職員研修では、機能より業務場面と規程確認が先 |
| 研修後は各自に任せればよい | 問い合わせ先、禁止領域、更新資料を示す必要がある |
