# 直接読む場合

`higher-ed-ai-skills` は AI エージェントにインストールして使うことを主用途にしています。ただし、GitHub 上で `SKILL.md` を直接読み、判断フレームワークとして参照することもできます。

## 読み方

1. [README.md](../README.md) の「業務別に頼む」から目的に近い skill を開く。
2. `SKILL.md` の `いつ使うか` と `使わない場面` を確認する。
3. `入力前の確認` と `判断軸` を読み、本文やファイルを渡す前に整理すべき情報を確認する。
4. `出力フォーマット` を使って、AI エージェントや人間の検討結果を同じ形に揃える。
5. `落とし穴` を読み、所属大学の規程、決裁権者、担当部署と照合する。
6. 必要に応じて `examples/` と `references/` を読む。

## 注意

- `SKILL.md` は AI エージェントが実行する protocol として書かれています。
- tool 呼び出し、ファイル読み取り、subagent dispatch など、人間が直接読んでも実行できない手順があります。
- 判断結果は所属大学の規程、決裁権者、担当部署の指示で上書きされます。

## GitHub に慣れていない場合

各 `SKILL.md` のページ右上にある Raw 表示から本文をコピーできます。AI に貼り付ける場合は、機密情報や学生データを同時に貼らないでください。

```text
以下の skill を使って、私のケースを判断してください。
ただし、まだ本文や実データは貼りません。
まず必要な情報カテゴリだけ質問してください。
```
