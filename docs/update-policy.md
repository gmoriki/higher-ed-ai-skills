# スキル鮮度管理方針 / Skill Update Policy

大学業務、AI サービス、制度、法令、各大学の運用は変化します。本ドキュメントでは、`higher-ed-ai-skills` の鮮度を維持するための改訂方針を定めます。

## 定期改訂

全 skill を対象としたレビューを年 2 回実施します。

| 時期 | 内容 |
|---|---|
| 3 月末 | 年度末レビュー。次年度の制度改正、学年暦、サービス変更を反映 |
| 9 月末 | 中間レビュー。上半期の変化と実運用からのフィードバックを反映 |

レビュー観点:

- 参照している AI サービスのデータポリシーに変更はないか。
- 引用している法規、通知、ガイドラインに改正はないか。
- 判断フローやチェックリストに実務上の不備が報告されていないか。
- 大学業務の現場語彙とずれていないか。
- 入力前トリアージ、確認先、出力フォーマット、落とし穴が保守されているか。

## トリガー改訂

以下のイベントが発生した場合、半期改訂を待たずに該当 skill を臨時改訂します。

### AI サービスのデータポリシー変更

- 主要 AI サービスの利用規約やデータ取り扱いポリシーが変更された場合。
- 学習データへの利用可否、データ保持期間、削除手順、法人契約条件に関する変更があった場合。

### 法改正・通知更新

- 個人情報保護法、著作権法、不正競争防止法など、AI 利用や大学業務に関連する法令の改正。
- 文部科学省、個人情報保護委員会、研究資金配分機関などの通知や要領の更新。
- 入試、学生支援、合理的配慮、研究倫理、内部質保証に関わる制度変更。

### 実務事故・運用不備

- AI 入力前トリアージの漏れ。
- 学生、入試、人事、研究データの取り扱い誤り。
- AI の誤案内が学生や研究者に不利益を与えた可能性。
- Skill の出力が所属大学の規程確認を促していなかった場合。

## 非推奨

技術やサービスの変化により内容が陳腐化した skill は、以下の手順で非推奨とします。完全削除はしません。過去に skill を参照・引用した利用者の利便性を保護するためです。

1. 該当 `SKILL.md` 冒頭に非推奨の旨を明記する。
2. 代替となる skill が存在する場合、その skill へのリンクを記載する。
3. skill のディレクトリを `deprecated/` に移動する。
4. [CHANGELOG.md](../CHANGELOG.md) に非推奨化の記録を残す。

非推奨 skill の記載例:

```markdown
> **[非推奨] この skill は 2026-09 に非推奨となりました。**
> 代替 skill: `new-skill`
> 理由: 判断軸が後継 skill に統合されたため。
```

## バージョニング

[Semantic Versioning](https://semver.org/) に準拠し、以下の基準で版番号を管理します。

| 変更の種類 | バージョン変更 | 例 |
|---|---|---|
| 誤字修正、リンク更新、表現の微修正 | patch | 1.0.0 -> 1.0.1 |
| 出力フォーマット追加、落とし穴追加、事例追加、trigger 拡張 | minor | 1.0.0 -> 1.1.0 |
| 判断ロジック、分類体系、前提条件の変更 | major | 1.x.x -> 2.0.0 |

### YAML frontmatter

各 `SKILL.md` の YAML frontmatter には以下を含めます。

```yaml
---
name: example-skill
description: >
  ユーザーの発話パターン、使う業務場面、返すものを簡潔に書く。
license: CC BY-SA 4.0
metadata:
  version: "1.0.0"
  last_updated: "2026-05-10"
  author: gmoriki
---
```

- `metadata.version`: 現在のバージョン番号。
- `metadata.last_updated`: 最終更新日。YYYY-MM-DD 形式。
- `description`: 機能説明ではなく trigger 設計。大学職員が実際に言いそうな相談文を含める。

## 変更履歴

すべての変更はリポジトリルートの [CHANGELOG.md](../CHANGELOG.md) に記録します。記録フォーマットは [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) に準拠します。
