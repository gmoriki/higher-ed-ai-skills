# AI エージェントへの頼み方

大学職員や研究支援職員は、`SKILL.md` を直接読むよりも、AI エージェントに業務状況を説明する形を基本にしてください。AI が必要な skill を読み、判断結果、根拠、次の行動を返します。

## 基本形

```text
higher-ed-ai-skills を使って、以下の業務を支援してください。

目的:
対象業務:
扱う資料の種類:
含まれそうな情報カテゴリ:
所属大学の関連ルール:
AI 実行環境:
知りたいこと:
```

機密情報を含む可能性がある場合は、本文やファイルを渡す前に概要だけで相談します。

```text
学生氏名、学籍番号、成績、相談記録を含む可能性がある資料です。
本文はまだ貼りません。
まず入力可否の事前トリアージをしてください。
追加で必要な情報があれば、本文ではなく情報カテゴリで質問してください。
```

## よく使う相談例

### 入力前トリアージ

```text
教授会資料を要約したいです。
議題には通常の報告事項、予算の途中経過、人事案件が混ざる可能性があります。
本文を渡す前に、AI に入力してよい範囲、確認すべき規程、使うべき環境を整理してください。
```

使われる主な skill:

- `check-info-level`
- `confidential-info-guidelines`
- `committee-meeting-minutes-ai`

### 会議運営

```text
来月から委員会議事録の作成負担を減らしたいです。
議題種別ごとに、録音、文字起こし、要約、配布前確認のどこで AI を使えるか整理してください。
```

使われる主な skill:

- `committee-meeting-minutes-ai`
- `confidential-info-guidelines`

### 学生問い合わせ

```text
履修、奨学金、証明書、留学生相談、障害配慮、メンタル不調の問い合わせがあります。
本文、学生氏名、学籍番号、相談本文はまだ渡しません。
カテゴリだけで、AI が定型回答してよいものと有人対応に回すものを分類してください。
```

使われる主な skill:

- `student-inquiry-triage`
- `confidential-info-guidelines`

### 多言語案内

```text
新入留学生向けオリエンテーション資料を複数言語で準備したいです。
本文や個別学生へのメールはまだ渡しません。
文書種別、公開範囲、個人情報の有無、AI 実行環境を前提に、
AI 翻訳で下書きしてよい範囲、確認者、配信前チェックを整理してください。
```

使われる主な skill:

- `multilingual-student-communication`
- `ai-tone-check`

### シラバスや授業方針

```text
来年度シラバスに、生成 AI の利用方針を明記したいです。
科目特性に応じて、許可する範囲、禁止する範囲、学生への説明文を案にしてください。
```

使われる主な skill:

- `syllabus-ai-policy`
- `ai-use-risk-classification`

### 入試

```text
総合型選抜の志望理由書について、生成 AI 使用方針を出願要項に入れたいです。
禁止表現、疑義発生時の確認手順、入試委員会に確認すべき論点を整理してください。
```

使われる主な skill:

- `entrance-exam-ai-policy`
- `ai-use-risk-classification`

### 研究支援・科研費・論文投稿

```text
科研費申請書の作成で AI を使った場合、どこまで開示すべきか相談されました。
研究者に返す標準回答、確認すべき公募要領、未発表研究構想の扱いを整理してください。
```

使われる主な skill:

- `research-integrity-ai-disclosure`
- `confidential-info-guidelines`

### IR・内部質保証

```text
学生アンケートの自由記述を AI で分類したいです。
匿名化前処理、利用してよい AI 環境、カテゴリ検証、報告時の注意点を整理してください。
```

使われる主な skill:

- `ir-freeform-text-analysis`
- `check-info-level`

### 広報文・学生向け案内

```text
オープンキャンパス告知文を AI で下書きしました。
大学広報として不自然な点、事実確認が必要な点、読者負荷を確認してください。
```

使われる主な skill:

- `pr-ai-checklist`
- `ai-tone-check`

### 組織導入・研修

```text
部署単位で AI 利用ルールを作りたいです。
禁止、限定、推奨、開放の区分で業務を整理し、委員会に出す論点表を作ってください。
```

使われる主な skill:

- `ai-use-risk-classification`
- `institutional-ai-adoption-checklist`
- `staff-ai-literacy-primer`

## AI に渡すとよい情報

- 目的
- 対象業務
- 想定利用者
- 資料種別
- 公開済み、学内限定、個人情報あり、未公表などの情報カテゴリ
- 所属大学の関連規程やガイドラインの要点
- 利用予定の AI 環境
- 期待する出力形式

## まだ渡さない情報

- 学生氏名、学籍番号、成績、相談履歴
- 入試、人事、懲戒、未公表研究データ
- 契約書、未公開議事録、内部稟議の全文
- API キー、パスワード、認証情報

必要な場合は、先に `check-info-level` で本文を読まない事前トリアージを依頼してください。

## うまく動かない時

AI が汎用的な回答をしてしまう場合は、次のように明示します。

```text
higher-ed-ai-skills の `check-info-level` と `student-inquiry-triage` を使って判断してください。
一般論ではなく、入力前確認、判定、根拠、推奨次アクション、最終確認先を分けて返してください。
```

使いたい skill がインストールされていない場合は、導入担当に [install.md](install.md) を共有してください。
