# 使い方

`higher-ed-ai-skills` は、大学職員が AI エージェントに大学業務を頼むための skill 集です。まず AI エージェントへインストールし、自然文で業務状況を説明して使います。

## 最初に読むもの

| 目的 | ドキュメント |

| AI エージェントに入れる | [install.md](install.md) |
| どう頼むか知りたい | [using-with-agent.md](using-with-agent.md) |
| GitHub 上で直接読みたい | [manual-reading.md](manual-reading.md) |
| 更新・鮮度管理を知りたい | [update-policy.md](update-policy.md) |

## 基本の順番

1. 本文やファイルを渡す前に、資料種別、情報カテゴリ、処理目的、AI 実行環境を説明する。
2. `check-info-level` または `confidential-info-guidelines` で入力可否を事前確認する。
3. 業務別 skill を使って、判断、文案、運用手順、確認先を整理する。
4. 所属大学の規程、決裁権者、担当部署で最終確認する。

## 例

```text
学生アンケート自由記述を分析したいです。
本文はまだ渡しません。
資料種別、含まれそうな情報、分析目的、利用予定の AI 環境をもとに、
入力前のトリアージと次に使う skill を提案してください。
```

## 重要な前提

- このリポジトリは「AI 活用そのもの」を目的にしません。
- 目的は、大学業務を AI エージェントに頼める形へ整えることです。
- 安全確認は主役ではなく、大学業務を止めないための前処理です。
